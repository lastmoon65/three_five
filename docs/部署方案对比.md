# 《红心对决》部署方案对比（低成本版）

- 版本：v1（2026-08-03）
- 前提：4 人私下娱乐、无赌博、非经营；已购自有域名（可暂不使用）。

## 结论

本地部署完全可行，成本可做到 0 元/月。推荐优先级：

1. 本地部署 + Tailscale 组网（0 成本，最推荐）
2. 本地部署 + 内网穿透免费版（朋友浏览器直开）
3. 特价轻量云（一年几十元，最省心）
4. 免费云（Oracle 等，0 成本但折腾）

## 方案对比

| 方案 | 月成本 | 朋友使用方式 | 稳定性 | 合规 | 适合 |
| --- | --- | --- | --- | --- | --- |
| 局域网（同一 WiFi） | 0 | 浏览器输局域网 IP | 线下稳定 | 无风险 | 偶尔线下聚会 |
| 本地 + Tailscale | 0 | 每人装 App，访问虚拟内网 | 看家里网络与设备 | 低风险 | 朋友愿意装 App |

| 特价轻量云（国内/香港） | 约 5~10 元 | 浏览器打开域名/IP | 高 | 国内需备案，香港无需 | 省心稳定 |
| 免费云（Oracle Always Free 等） | 0 | 浏览器直开 | 中（可能被回收） | 无需备案 | 愿意折腾 |

## 方案说明

### 1. 本地部署 + Tailscale（推荐，0 成本）

- 任意一台能常开的旧电脑/笔记本即可（1G 内存也够，2C4G 更稳）。
- Tailscale 免费组网：4 人各装客户端（iOS/Android/Win/Mac 都有），像在局域网里一样访问你的服务。
- 优点：免费、加密、无需公网 IP、无需备案、无需端口映射；已购域名可以先闲置。
- 缺点：朋友要装一个 App；你家断电/断网就玩不了。
- 数据量：棋牌消息极小，家庭上行带宽完全足够。

### 2. 本地部署 + 内网穿透（0 成本）

- 用 cpolar / 花生壳免费版把本地服务暴露成公网链接。
- 朋友浏览器直接打开链接，什么都不用装。
- 免费版：随机域名、限速（约 1Mbps）、限时长，对棋牌流量够用；想绑定自己的域名需要付费版（约几十~百元/年）。
- 不建议：家庭宽带直接做 80/443 端口映射 + DDNS（运营商通常封 80/443，且暴露公网有风险，严格说也涉及备案）。

### 3. 特价轻量云（一年几十元）

- 腾讯云/阿里云轻量服务器新用户活动价，常见一年 40~100 元（国内或香港节点）。
- 浏览器直开、体验最稳、不用管家里设备。
- 国内节点需要 ICP 备案；香港节点无需备案。

### 4. 永久免费云（Oracle Cloud Always Free）

- 提供 2C1G AMD + 4C24G ARM 免费实例，配置足够。
- 需要注册并验证信用卡，国内访问延迟一般，实例有被回收的风险。
- 只作为折腾选项，不作为首选。

## 对架构的影响

- **没有影响**：架构不变（H5 前端 + 权威服务端 + WebSocket），只是部署目标不同。
- 部署文档把"运行环境"参数化：本机 / 局域网 / 穿透 / 云服务器均可。
- HTTPS：Tailscale 自带加密；穿透方案由服务商提供 HTTPS；云方案用免费证书。
- 域名：本地方案可暂不使用已购域名，以后上云或购买穿透付费版时再绑定。

## 建议

1. 先按"本地部署 + Tailscale"设计，0 成本启动。
2. 若朋友嫌装 App，再叠加或切换内网穿透（浏览器直开）。
3. 守住红线：不公开、不收费、无充值兑换；小范围非经营性使用，合规风险低。
