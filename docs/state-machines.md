# 《红心对决》状态机设计

## 1. 连接与会话

未连接 → 已连接(未认证) → 已认证 → 已入房 → 游戏中
任意阶段断线 → 断线(等待重连)；重连成功回到断线前状态（游戏内由服务端下发快照）。

## 2. 房间状态机

WAITING ⇄ PLAYING → 结算后回 WAITING（重新准备）

- WAITING：0~4 人；**4 人在线且全部已准备**后，房主可点"开始"（离线玩家不计入就绪）。
- PLAYING：锁定座位，禁止加入/换人。
- 解散：仅房主主动离开时触发，所有人回大厅（游戏中解散 = 本局作废）。

## 3. 对局阶段状态机

DEAL → REVEAL → TRIBUTE? → BURY → TRICK(循环) → ROUND_END → 回 WAITING

| 阶段 | 说明 |
| --- | --- |
| DEAL | 服务端洗牌发牌（每人12张，底牌6张），广播 |
| REVEAL | 按座位顺序询问是否亮三五反；每人选择"亮/不亮"；全部完成后进入下一步 |
| TRIBUTE | 依据上一副闲家得分决定单/双进贡或无；造反成立则跳过；进贡→退贡 |
| BURY | 仅庄家：拿6张底牌 → 选6张扣回 → 公开 |
| TRICK | 领出者出牌（决定维度）→ 其余三家按逆时针响应 → 服务端裁决 → 赢家领出下一墩，循环至手牌打完 |
| ROUND_END | 计算双方得分、换庄/连庄/进贡结果，展示结算，回房间 WAITING |

## 4. 断线重连状态机

游戏中任意玩家断线 → GAME_PAUSED（暂停等待）→ 重连成功 → 下发快照 → 继续

- 不代打、不判负、无限等待。
- 房主可"解散房间"（本局作废，所有人回大厅）。
- 房间阶段断线：席位标记"离线"，席位长期保留、不超时释放；其余人可继续操作。

## 6. 房间规则（产品已确认 2026-08-03）

1. 房主离线/不在：**不转让、不自动解散**，房间一直等待；其他玩家可主动退出房间，另建或加入新房间。
2. 离线玩家席位长期保留（标记"离线"），重连后回到原席位并**保留准备状态**。
3. 开始游戏条件：4 个席位占满、**全部在线**、**全部已准备**。
4. 换位：等待阶段可互换 3/4 号位（房主座位固定），准备状态跟随玩家移动。

## 5. 关键迁移表

| 事件 | 前置状态 | 后置状态 |
| --- | --- | --- |
| 4 人 ready + 房主 start | WAITING | PLAYING/DEAL |
| 发牌完成 | DEAL | REVEAL |
| 亮牌完成 | REVEAL | TRIBUTE 或 BURY（无进贡时） |
| 进贡/退贡完成 | TRIBUTE | BURY |
| 埋底完成 | BURY | TRICK |
| 一墩完成且仍有手牌 | TRICK | TRICK（换领出者） |
| 一墩完成且手牌打空 | TRICK | ROUND_END |
| 结算展示完成 | ROUND_END | WAITING |
| 玩家断线 | 任意游戏阶段 | GAME_PAUSED |
| 重连成功 | GAME_PAUSED | 原阶段 |
| 房主主动离开 | 任意 | 解散 → 大厅 |

## 6. 座位与轮转约定

- 座位 0/2 为一队，1/3 为一队（对家为队友）。
- 出牌顺序逆时针：seat 的下一位 = (seat+3)%4。
- 换庄：新庄家 = 原庄家下家 (dealer+3)%4；连庄满 3 副 → 队友 (dealer+2)%4。
- 首副庄家：服务端随机。
