# 《红心对决》二期状态机设计（6 人两副牌模式）

- 版本：v2.0（2026-08-03）
- 说明：仅描述 6 人模式新增/差异；未提及的一期状态机（连接、断线重连、房间基本流转）原样复用。

## 1. 房间状态机（按模式隔离）

```
（登录）→ 模式选择（p4 | p6）→ 大厅 → WAITING ⇄ PLAYING → 结算后回 WAITING
```

### 1.1 模式与房号

| 模式 | room.mode | 房号位数 | 座位数 | 开局条件 |
| --- | --- | --- | --- | --- |
| 4 人 | `p4` | 4 位 | 4 | 4 席满 + 全在线 + 全准备 |
| 6 人 | `p6` | 6 位 | 6 | 6 席满 + 全在线 + 全准备 |

- 房间号生成按模式；`join_room` 先按房号位数预判模式，再校验 room.mode，不一致返回 `JOIN_MODE_MISMATCH`。
- 两种模式的房间互不可见、互不可加入。
- 房主主动离开 → 解散（本局作废，成员回大厅）；房主离线 → 等待重连，不转让（与一期一致）。

### 1.2 WAITING → PLAYING 迁移

| 事件 | 前置 | 后置 |
| --- | --- | --- |
| 6 席满 + 全员在线 + 全员准备 + 房主 start_game | WAITING | PLAYING/DEAL |
| 6 人模式创建房间（mode=p6） | 大厅 | WAITING(6 空席) |
| 玩家断线（房间阶段） | WAITING | WAITING（席位标记离线，长期保留） |

## 2. 对局阶段状态机（6 人两副牌）

```
DEAL → REVEAL → TRIBUTE? → BURY → TRICK(循环) → ROUND_END → 回 WAITING
```

| 阶段 | 说明（6 人差异点加粗） |
| --- | --- |
| DEAL | 两副牌 108 张，**每人 17 张，底牌 6 张，全部发完**；CardDTO.id 带副序号 |
| REVEAL | 6 人按逆时针轮询亮三五反（顺序：庄家 → 逆时针逐位）；**闲家方生效亮番人数决定造反等级 0/1/2** |
| TRIBUTE | 按 200 分制阈值触发：<80 无 / 80~119 换庄 / 120~159 单进贡 / 160~200 三进贡；**造反 1 人免单进贡、≥2 人免三进贡（换庄照常）** |
| BURY | 庄家拿 6 张底牌（23 张），选 6 张扣回并公开；**分牌 ≥12 张触发兜底**（扣最小 6 张，分归庄家方） |
| TRICK | 6 人逆时针，首墩庄家先出；**单次最多 4 张（真杠/假杠/四清固定 4 张，甩牌例外）**；8 张同点拆两副 |
| ROUND_END | 双方得分合计 200；换庄/连庄/造反结果；下一副庄家；回 WAITING |

### 2.1 关键迁移表

| 事件 | 前置 | 后置 |
| --- | --- | --- |
| 6 人 ready + 房主 start | WAITING | PLAYING/DEAL |
| 发牌完成 | DEAL | REVEAL |
| 6 人亮牌完成 | REVEAL | TRIBUTE 或 BURY（无进贡时） |
| 进贡/退贡完成 | TRIBUTE | BURY |
| 埋底完成 | BURY | TRICK |
| 一墩完成且仍有手牌 | TRICK | TRICK（换领出者） |
| 一墩完成且手牌打空（每人 17 张 = 17 墩） | TRICK | ROUND_END |
| 结算展示完成 | ROUND_END | WAITING |
| 玩家断线 | 任意游戏阶段 | GAME_PAUSED（等待重连） |
| 重连成功 | GAME_PAUSED | 原阶段（快照续局） |
| 房主主动离开 | 任意 | 解散 → 大厅 |

## 3. 6 人座位与轮转约定

- 队伍：`team = seatId % 2`；座位 0/2/4 一队，1/3/5 一队（对应规则文档"1、3、5 对 2、4、6"）。
- 出牌顺序逆时针：下家 = `(seat + 5) % 6`；亮牌顺序从庄家起逆时针逐位。
- 对位配对（进贡/退贡）：`(seat + 3) % 6`（0↔3、1↔4、2↔5）。
- 换庄：闲家得分 ≥80 → 新庄家 = 原庄家下家 `(dealer + 5) % 6`，连庄计数清零。
- 连庄：闲家得分 <80 → 连庄 +1；满 3 副 → 由逆时针最近队友接任 `(dealer + 4) % 6`，计数清零。
- 首副庄家：服务端随机（与 4 人一致，待确认项见决策清单）。

## 4. 造反状态（二期新增子状态）

| 事件 | 结果 |
| --- | --- |
| 闲家方 0 人亮番成功 | rebellionLevel = 0，进贡按 5.1 阈值正常执行 |
| 闲家方 1 人亮番成功 | rebellionLevel = 1，120~159 档不执行进贡（换庄照常） |
| 闲家方 ≥2 人亮番成功 | rebellionLevel = 2，120 分以上各档均不执行进贡（换庄照常） |
| 庄家方亮番成功 | 无造反效果，仅可阻止闲家（先亮/覆盖规则与一期一致） |

- 服务端在 REVEAL 结束时计算 rebellionLevel 并随 game_state 下发；TRIBUTE 阶段按它裁剪进贡档位。

## 5. 断线重连（复用一期，无差异）

- 不代打、不判负、无限等待；GAME_PAUSED 期间其余玩家可看到"等待重连"提示。
- 重连通过 token 鉴权，服务端下发全量快照（GameDTO，含 myHand 与当前阶段），续局。
