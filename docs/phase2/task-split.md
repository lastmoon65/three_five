# 《红心对决》二期任务拆分与验收标准

- 版本：v2.0（2026-08-03）
- 原则：测试先行、单 agent 串行推进（一期教训）；每个任务独立可验收；4 人模式回归门槛 70/70。

## 0. 依赖顺序

```
T1(core 抽取) → T2~T7(引擎 6 人) → T8(房间模式) → T9(集成)
          ↘ 引擎稳定后 → F1~F4(前端)
回归测试贯穿始终；公网 E2E 最后做
```

## 1. 后端任务

| 编号 | 任务 | 验收标准 |
| --- | --- | --- |
| T1 | 从 game.mjs 抽取 `game/core.mjs`（牌力/牌组/维度/墩裁决/甩牌前 N 张/四清垫分） | 4 人 70 项测试全绿；Game 行为零变化（diff 只搬不写新逻辑） |
| T2 | Game6：两副牌构造（108 张、id 带副序号）、发牌（每人 17、底 6）、牌力/常主/主牌判定 | 单测：108 张无重复 id；每人 17 张互不重叠；主牌占比 46/108 |
| T3 | Game6：亮牌（6 人轮询、三五反、同级别先亮有效）与**分层造反**（rebellionLevel 0/1/2） | 单测：闲家 1 人亮 → level 1；2 人 → level 2；庄家方亮不生效 |
| T4 | Game6：进贡/退贡（200 分制阈值 80/120/160；单/三进贡；对位配对；造反裁剪） | 单测：四档得分各一局；单进贡 1 组配对；三进贡 3 组按 (seat+3)%6；造反免贡 |
| T5 | Game6：埋底（23 张选 6 公开；无分约束；分牌 ≥12 兜底） | 单测：正常无分底；12 张分牌触发兜底且分归庄家方；非庄家越权拒绝 |
| T6 | Game6：打牌裁决（6 人逆时针、首墩庄家、4 张上限、8 张同点拆分、甩牌、同牌力先出者大、四清垫分） | 单测：真杠 4/8 张边界；两副 KKKK 先出者大；17 墩打完；每副总分 200 |
| T7 | Game6：轮庄与结算（<80 守庄/≥80 换庄下家；连庄 3 副逆时针最近队友接任；下一副带入） | 单测：两副连打轮庄正确；连庄满 3 副队友接任 |
| T8 | net-server 房间：create_room{mode}、房号 4/6 位隔离、6 座房间、开局校验 | room 单测：p4 号不能加 p6 房；6 人未满不能 start；6 席满+全准备可开局 |
| T9 | 集成：6 人全流程（发牌→亮牌→进贡→埋底→打牌→结算→轮庄）+ 断线重连 + seq | game-net 6p 版测试全绿；重连恢复快照继续 |

## 4. 交付顺序建议

1. T1（core 抽取）→ 跑 4 人回归，绿了再继续。
2. T2~T7 按顺序推进，每个任务带单测，单 agent 串行。
3. T8、T9（房间 + 集成），本地 6 人测试全绿。
4. F1~F4 前端（引擎已稳定，前端只做渲染）。
5. E4 公网验收，通过后同步 deploy-live 上线。
