# 《红心对决》任务拆分与验收

开发路线：**单机版先行（M0），联网版后置（M1~M8）**。

单机版 = 同一台设备四人轮流操作（传手机/传电脑），目的是把规则流程和游戏界面先跑通。规则引擎做成无依赖的纯 JS 模块，单机版与联网版**完全复用同一份引擎**。

## 里程碑

| 里程碑 | 内容 | 负责 |
| --- | --- | --- |
| M0 单机版 | 规则引擎 + 五区游戏页 + 完整一副流程（发牌→亮牌→进贡→埋底→打牌→结算→轮庄），同屏轮流操作 | 引擎+前端+测试 |
| M1 联网骨架 | 服务启动、静态页、WS 连通、auth（4 账号） | 后端+前端 |
| M2 房间 | 建房/加入/准备/离开/解散、room_updated | 后端+前端 |
| M3 发牌+亮牌（联网化） | 把单机功能迁移到 WS 通道 | 后端+前端 |
| M4 进贡+埋底（联网化） | 同上 | 后端+前端 |
| M5 打牌（联网化） | 同上 | 后端+前端 |
| M6 结算+轮庄（联网化） | 同上 | 后端+前端 |
| M7 断线重连 | 暂停等待、快照恢复、房主解散 | 后端+前端 |
| M8 联调验收 | 端到端、防作弊回归 | 全角色 |

## M0 单机版任务（先行）

| 编号 | 任务 | 验收 |
| --- | --- | --- |
| R1 | 规则引擎纯 JS 模块（无 DOM/网络依赖）：牌力/发牌/亮牌/进贡/埋底/打牌六维度/结算轮庄 | 可在浏览器与 Node 双端运行 |
| R2 | 单机 UI：五区布局、当前座位手牌可见、其余三家牌背、出牌交互、动画 | 四人轮流可完整玩一副 |
| R3 | 规则引擎单测 | 每个规则条款映射用例，全绿 |
| R4 | 单机端到端：发牌到结算再到下一副轮庄 | 流程闭环 |

## 联网版任务（M1 之后）

### 后端任务

| 编号 | 任务 | 验收 |
| --- | --- | --- |
| B1 | 连接/鉴权/token（单会话顶号） | 错误密码拒绝；重复登录顶号 |
| B2 | 房间模块（状态机） | 加入/准备/开始/解散符合状态机 |
| B3 | 规则引擎接入 WS（复用 M0 引擎） | 引擎零改动 |
| B4 | 亮牌联网化 | 造反/五反>三反正确 |
| B5 | 进贡退贡联网化（含兜底） | 40/60/80 边界正确 |
| B6 | 埋底联网化（含兜底） | 无分约束正确 |
| B7 | 打牌联网化（服务端校验） | 六维度裁决正确 |
| B8 | 结算轮庄联网化 | 换庄/连庄3副正确 |
| B9 | 断线暂停与快照 | 重连后局面一致 |

### 前端任务

| 编号 | 任务 | 验收 |
| --- | --- | --- |
| F1 | 登录页 + token 存取 | 错误提示按 PRD |
| F2 | 大厅（创建/加入） | 房号 6 位 |
| F3 | 房间页（4席位/准备/复制房号/开始） | 实时刷新 room_updated |
| F4 | 游戏页联网化（WS 状态渲染） | 只渲染服务端状态 |
| F5 | 发牌/理牌动画 | 见 PRD 第五幕 |
| F6 | 亮牌/进贡/埋底交互 | 选择后可提交 |
| F7 | 出牌交互 + 合法牌高亮 | 非法选择给出提示 |
| F8 | 结算页 | 展示 round_end 数据 |
| F9 | WS 客户端（连接/心跳/重连/快照） | 断线自动重连恢复 |

### 测试任务

| 编号 | 任务 | 覆盖 |
| --- | --- | --- |
| T1 | 规则引擎单测（持续） | 每个规则条款映射一个用例 |
| T2 | 契约测试 | 消息格式、数据最小化（无他方手牌） |
| T3 | 端到端 | 4 人联网完整一副 → 结算 → 下一副轮庄 |
| T4 | 异常/防作弊 | 断线等待/重连/房主解散/顶号/非法出牌/伪造事件 |
| T5 | 回归报告 | 修复后全量关联用例 |

## 验收标准（DoD）

- 单机版：同屏四人可完整玩一副，换庄/进贡/结算正确。
- 联网版：4 人通过浏览器完整玩一副；任一作弊尝试失败；断线重连局面一致。
- P0/P1 用例全绿。
