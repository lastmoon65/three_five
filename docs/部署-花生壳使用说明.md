# 部署说明：用花生壳给朋友远程玩《红心对决》

- 版本：v1（2026-08-03）
- 前提：本地电脑能跑起联网版（`node net-server.mjs`，端口 8090），已确认 `http://localhost:8090` 正常。
- 结论：**不需要买域名**。花生壳免费版送一个 1 年有效期的壳域名；需手机号实名认证（15 天内完成）；免费限制：带宽 1Mbps、每月流量 1GB、外网随机端口（免费，固定端口收费）。

## 一、本地先自测

1. 在项目目录运行：`node net-server.mjs`，浏览器打开 `http://localhost:8090` 确认登录页正常。
2. 局域网自测（可选但推荐）：查本机局域网 IP（`ipconfig`），手机连同一个 WiFi 访问 `http://本机IP:8090`。
   - 若打不开：检查 Windows 防火墙入站规则，放行 8090 端口。
   - 局域网通 = 服务器和防火墙没问题，剩下的只是"外网怎么进"。

## 二、注册与实名

1. 打开贝锐花生壳官网：`hsk.oray.com`，用手机号注册贝锐账号。
2. 登录后系统会赠送一个免费壳域名（形如 `xxxxx.vicp.cc`）。
3. 按提示在 15 天内完成**实名认证**（《网络安全法》要求，未实名无法使用内网穿透）。

## 三、安装客户端

1. 官网下载 Windows 版花生壳客户端，安装并登录。
2. 登录后能看到自己的壳域名和"内网穿透"功能入口。

## 四、添加映射（核心步骤）

在客户端里：

1. 进入「内网穿透」→「添加映射」。
2. 应用名称：红心对决。
3. 映射类型：**HTTP**（网页应用选 HTTP；免费版 HTTPS 支持有限，先用 HTTP）。
4. 内网主机：`127.0.0.1`。
5. 内网端口：`8090`（联网版端口；单机版 8080）。
6. 外网域名：选择系统分配的免费壳域名。
7. 外网端口：选**随机端口**（免费）。
8. 提交，生成外网访问地址（形如 `http://xxxxx.vicp.cc:12345`）。

## 五、验证与分享

1. 本机浏览器打开生成的外网地址，应看到《红心对决》登录页。
2. 手机**关掉 WiFi 用 4G/5G** 打开同一地址，确认外网可访问。
3. 把地址发给朋友（浏览器直开即可，无需装任何东西）。

## 六、注意事项

- **电脑和花生壳客户端都要保持运行**：服务器关了或客户端退出，游戏就下线。
- 免费额度：1Mbps 带宽 + 每月 1GB 流量，棋牌消息极小（一局几 MB），正常玩一个月用不完；但别用来传输大文件。
- 免费壳域名有效期 1 年，到期前留意官网续期规则。
- HTTP 是明文传输，私人小圈子可接受；如果介意，备选 cpolar 免费版（直接给 HTTPS 随机域名，步骤类似）。
- 如果朋友反映卡顿/打不开：先确认服务器在线 → 客户端在线 → 流量是否超限。
- 想要固定端口或绑定自己的域名 → 花生壳付费版；或者直接换香港云服务器（自有域名可用，无需备案）。
